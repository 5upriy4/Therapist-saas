3. CORE ARCHITECTURE & FEATURES
--------------------------------------------------------------------------------
1. Centralized Entitlement Engine:
   Config-driven subscription tiers (Starter vs Growth) controlling access to 
   clinical tools, packages, and analytics via single-source-of-truth service.

2. Confidential Clinical Documentation (Mental Healthcare Act, 2017):
   Structured SOAP & DAP templates with auditable digital intake consent. 
   Strict database-level projection ensuring private therapist reflections are 
   never exposed to client-facing routes.

3. Timezone Scheduling & Slot Management:
   Instant IST / UTC conversion with customizable practitioner buffer times 
   and real-time conflict detection.

4. Payments & GST Invoicing:
   Razorpay checkout flow (with automatic sandbox simulation) and automatic 
   itemized GST invoice PDF generation via PDFKit.

5. Real-Time Chat & Telehealth:
   Socket.io powered instant messaging between therapist and client with read 
   receipts and typing indicators.

4. LOCAL SETUP (IF EXAMINER WISHES TO RUN LOCALLY)
--------------------------------------------------------------------------------
Backend:
  1. cd unfazed-backend
  2. npm install
  3. node server.js  (Starts on http://localhost:5000)

Frontend:
  1. cd unfazed-frontend
  2. npm install
  3. npm run dev     (Starts on http://localhost:5173)

The cloud database on MongoDB Atlas is already seeded and active.
